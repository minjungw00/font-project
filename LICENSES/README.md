# 라이선스 및 릴리스 게이트

기반 글꼴 Sarasa Gothic v1.0.43의 원문 라이선스는 [Sarasa-OFL.txt](Sarasa-OFL.txt)에 보존합니다. 파생 글꼴에는 OFL 1.1 및 모든 관련 저작권 고지를 유지해야 합니다. Sarasa가 계승한 예약 이름 Source를 새 패밀리 이름에 사용하지 않습니다.

- [Sarasa v1.0.43 LICENSE](https://github.com/be5invis/Sarasa-Gothic/blob/v1.0.43/LICENSE)
- [Iosevka](https://github.com/be5invis/Iosevka)
- [Source Han Sans](https://github.com/adobe-fonts/source-han-sans)
- [Nerd Fonts v3.5.1 라이선스 감사](https://github.com/ryanoasis/nerd-fonts/blob/v3.5.1/license-audit.md)
- [Material Design Icons 라이선스 및 상표 안내](https://pictogrammers.com/docs/general/license/)

## 릴리스 전 검토

| 구성 요소 | upstream 명시 라이선스 |
|---|---|
| Sarasa / Iosevka / Source Han Sans | OFL 1.1 |
| Nerd Fonts 패처 코드 | MIT |
| Material Design Icons | Apache 2.0 (브랜드·로고 예외 확인) |
| Font Awesome, Codicons | CC BY 4.0 |
| Font Awesome Extension, Devicons, Octicons, IEC Power Symbols, Seti, Powerline Extra | MIT |
| Font Logos | Unlicense (상표권 별도) |
| Weather Icons, Pomicons | OFL 1.1 |
| Powerline Symbols | upstream의 개별 라이선스 원문 확인 필요 |

위 표는 Nerd Fonts의 감사 문서를 출발점으로 한 목록이며 완전한 재배포 허가 검토를 대신하지 않습니다. 배포 전에 실제 패치된 모든 집합에 대해 원문 라이선스, 저작자, 수정 고지, NOTICE 및 상표권 예외를 점검하고 동봉합니다. 특히 브랜드 로고를 홍보나 제품 식별 표장으로 사용하는 권리는 글꼴 라이선스와 별개입니다.

이 저장소에 새로 작성된 빌드 코드의 배포 라이선스와 최종 폰트 이름은 소유자가 결정할 사항입니다. 현재는 신규 코드에 별도의 라이선스를 부여하지 않으며, 원본 글꼴의 OFL을 유지합니다. 검증된 라이선스 번들 없이 글꼴 바이너리를 공개 릴리스하지 않습니다.
